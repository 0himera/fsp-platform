# Цифровая платформа ФСП РД (ТехноСпортФест – 2026)

Единая цифровая платформа Федерации спортивного программирования Республики Дагестан для спортсменов, организаторов, результатов соревнований и рейтинга.

## Структура репозитория

- `frontend/` — клиентская часть на Next.js 16 (App Router), React 19, Feature-Sliced Design (FSD), TanStack Query v5 и shadcn/ui.
- `backend/` — серверная часть и база данных платформы.
- `docs/` — регламенты, положения и документация фестиваля.

## Запуск frontend

```bash
cd frontend
bun install
bun dev
```
